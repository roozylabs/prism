# RoozyLabs Prism — Business Analytics & Performance Metrics Guide

## 1. Core Business & Technical Metrics

When evaluating AI Gateway performance and business efficiency, analyze these 4 key dimensions:

### 1.1. Token & Usage Analytics
- **Prompt Tokens**: Number of input tokens processed by upstream providers.
- **Completion Tokens**: Number of output tokens generated by models.
- **Total Tokens**: Sum of prompt + completion tokens used per request, key, or provider.
- **Cost Efficiency**: Token consumption broken down by model slug (`gemini-3.6-flash`, `gpt-4o`, `claude-3-7-sonnet`, `big-pickle`).

### 1.2. Latency & Performance (SLA)
- **Time to First Token (TTFT)**: Elapsed time in milliseconds before the first streaming token header arrives at the client. Target TTFT is **< 1,500 ms**.
- **Total Latency**: Total duration of request execution in milliseconds.
- **Provider Latency Comparison**: Benchmark latency across providers to optimize model routing defaults.

### 1.3. Error & Reliability Metrics
- **Rate Limit Frequency (HTTP 429)**: Count of rate limit / quota exceeded errors per provider key. High 429 frequency triggers automatic 24-hour cooldown backoffs.
- **Service Availability (HTTP 503 / 500)**: Upstream availability percentage.
- **Failover Success Rate**: Percentage of requests successfully recovered by AI Gateway's automatic credential rotation.

### 1.4. Key & Tenant Quota Management
- **Request Count per Gateway Key**: Volume of API calls generated by each client key (`prism_sk_*`).
- **Quota Tiers**: Allocation of rate limits (requests per minute / requests per day) per key tier.

## 2. Request Logs Schema for Business Analysis (`request_logs`)

Log fields in database for analytics queries:

| Column Name | Business Meaning |
| :--- | :--- |
| `gateway_api_key_id` | Client key identifier (`prism_sk_*`) |
| `provider_id` | Target provider (OpenAI, Anthropic, Google, OpenCode) |
| `credential_id` | Credential API Key used for upstream call |
| `model` | Requested model slug |
| `status_code` | HTTP status code returned (200, 429, 503, 404) |
| `latency_ms` | Execution duration in milliseconds |
| `input_tokens` | Prompt token count |
| `output_tokens` | Completion token count |
| `total_tokens` | Total token count |
| `retry_count` | Number of failover retries executed before success |
| `error_message` | Error detail if request failed |
| `created_at` | Timestamp of request execution |
